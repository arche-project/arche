# Rapport M0-1 — Publier le dépôt sur GitHub, ci.yml vert

Date : 2026-09-12 · Taille : S · Décision : D6 (github.com/arche-project/arche) · Débloque : M0-2, M0-3.

## Ce qui a été fait

- **Organisation `arche-project` et dépôt public `arche`** créés sur GitHub ; premier push de
  `main` (`70f528e`, « Arche — first public commit (ADR 0013, 0015; backlog v2) »). Licence MIT
  visible sur la page du dépôt.
- **CI** : trois runs pour arriver au vert.
  - #1 rouge : `check-schema-ajv` refusait deux URL de page d'accueil Hesperian contenant des
    caractères non ASCII et une apostrophe → percent-encodées dans
    `catalog/resources/first-line-care.yaml` ; `actions/checkout` et `setup-node` passés en v5
    (`42c8c47`).
  - #2 rouge : macOS — message d'eval dépendant de la locale (`ARCHE_LANG=fr` forcé dans le
    test) et `sqlite3` système sans FTS5 (test sauté quand la sonde `CREATE VIRTUAL TABLE …
    USING fts5` échoue) ; Windows — EBUSY au nettoyage des fichiers SQLite et faux outil `sh`
    → ticket **M3-7** ouvert, `continue-on-error` pour `windows-latest` seulement,
    `.gitattributes` (`* text=auto eol=lf`) (`5ee32e4`).
  - #3 **vert** sur Ubuntu et macOS ; Windows mesuré, non bloquant jusqu'à M3-7.
- **README.md** : badges CI et licence (`c59920e`).
- **Actions → Workflow permissions** : réglé au niveau de l'organisation (le réglage du dépôt
  était verrouillé par la politique d'org) : *Read and write* + *Allow GitHub Actions to create
  and approve pull requests* — nécessaire à `catalog-update.yml`, qui ouvre des PR (M2-3).
- **Ruleset `protect-main`** (Active, cible : branche par défaut `main`) : *Require a pull
  request before merging* (0 approbation requise — un mainteneur seul ne peut pas approuver sa
  propre PR ; le garde-fou est la CI), *Require status checks to pass* avec
  `test (ubuntu-latest, 22)` et `test (macos-latest, 22)` (Windows non requis jusqu'à M3-7),
  *Block force pushes*, *Restrict deletions*. Liste de bypass vide : les mainteneurs passent par
  des PR comme tout le monde (PUBLICATION.md §4).
