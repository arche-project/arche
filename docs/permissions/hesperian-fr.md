## Pourquoi cette demande est forte

Les éditions françaises (Guide des sages-femmes, Là où les femmes n'ont pas de docteur, Là où il n'y a pas de dentiste) n'existent **qu'en HTML sur fr.hesperian.org** : il n'y a aucun PDF français. Un lecteur francophone hors connexion n'a donc aujourd'hui **aucun moyen** d'accéder à ces livres — ce qui est exactement la population que Hesperian cherche à servir.
