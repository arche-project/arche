# Autorisations écrites / Written permissions

Un fichier par source dont la licence seule n'autorise pas la publication d'un ZIM par Arche (clauses NC, licence absente ou mixte).
Tant que le fichier n'existe pas avec la mention « accord reçu », la recette correspondante reste `permission: pending` et le workflow refuse de construire.

Modèle : `docs/permissions/TEMPLATE.md`. Le mail type à envoyer est dans `docs/fr/HEBERGEMENT.md`.

One file per source whose license alone doesn't allow Arche to publish a ZIM (NC clauses, missing or mixed license).
Until the file exists and says "permission received", the recipe stays `permission: pending` and the workflow refuses to build.
