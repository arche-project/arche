# Printable sheets (EN)

One page each. Print, laminate, keep in a binder and **in the library's box**.
They don't replace the manuals (Hesperian, IFRC, Sphere): they serve when there is no time to open them.
Each sheet says where to read more in the Arche library.

| Sheet | When |
|---|---|
| [01 — Safe drinking water](01-safe-water.md) | from day one without a trusted water supply |
| [02 — Bleeding, wounds, burns](02-first-actions.md) | emergency |
| [03 — Dehydration, diarrhoea (ORS)](03-rehydration.md) | first avoidable cause of death |
| [04 — Keeping food without a fridge](04-preservation.md) | week 1 |
| [05 — Communicating without a network](05-communicate.md) | prepare beforehand |
| [06 — Restarting the library and reading these files again](06-reading-the-library.md) | when the usual computer is dead |
| [07 — What kills: mushrooms and plants](07-deadly.md) | **before** any foraging |
| [08 — The numbers of self-reliance](08-numbers.md) | **before** buying land, a stove or panels — and before winter |

Sources: WHO, IFRC, Hesperian (*Where There Is No Doctor*), Sphere, CDC. Sheets are CC BY-SA 4.0 (Arche project); always check the cited source.
